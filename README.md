# World Trigger — Future Continuity

แฟนฟิกชันที่ดำเนินเรื่องโดย **ตัวเอกใหม่ (Original Character)** ราว 4–5 ปีหลังตอนจบ World Trigger **ฉบับสมมติของผู้เขียน** (T0) ไม่ใช่ภาคต่อทางการ

## เหตุการณ์ที่ตกลงแล้ว
- Canon cutoff เป็นช่วงกลุ่มตัวเอกพบกลุ่ม B ชั้นบนในการสอบเลื่อนระดับรอบสุดท้าย (ยังต้องตรวจบทที่แน่นอน)
- หลัง cutoff กลุ่มพระเอกเดินทางไปโลกเนเบอร์และกลับมาได้
- คุกะ ยูมะกลับเป็นมนุษย์ปกติ และต่อมากลายเป็นเจ้าหน้าที่ Border ระดับ S
- โอซามุ จิกะ และฮิวส์ยังอยู่ทีมเดิมระดับ B ชั้นบน เป็นทีมที่ร่วมงานจนเชี่ยวชาญ
- ตัวละครเอกใหม่ยังไม่ได้กำหนดชื่อ ภูมิหลัง Trigger หรือสายสัมพันธ์กับกลุ่มเดิม

## วิธีใช้กับ Git / Obsidian / ChatGPT
1. Clone repo แล้วเปิด root เป็น Obsidian vault
2. อ่าน `AGENTS.md` และ `00_Project/Story_Bible.md` ก่อนเริ่มเขียน
3. เติมข้อมูล `03_Characters/Original/OC-PROTAGONIST.md` โดยใช้แม่แบบใน `99_Templates/`
4. ใช้ `04_Timeline/Master_Timeline.md` และ `02_Future_World/Bridge_Timeline.md` เพื่อตรวจความต่อเนื่อง
5. สำหรับข้อมูลตัวละครต้นฉบับและ Trigger ดู `01_Source_Canon/Border_Personnel/README.md`, `01_Source_Canon/Triggers/Agent_Loadouts.md` และ `Trigger_Catalog.md`
6. ใช้ `07_AI_Context/Context_Rules.md` เพื่อจัดบริบทก่อนเขียนฉาก; การเปิด GitHub ไม่ได้ทำให้ ChatGPT อ่าน repo ทั้งหมดโดยอัตโนมัติ

## สถานะความจริง
- `source_canon`: มังงะต้นฉบับก่อน cutoff
- `hypothetical_ending`: ตอนจบที่ผู้เขียนสมมติ
- `future_continuity`: ผลลัพธ์ 4–5 ปีให้หลัง
- `original_fiction`: ตัวละครและเนื้อเรื่องใหม่
