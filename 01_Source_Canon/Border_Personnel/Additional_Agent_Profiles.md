## กติกาใช้งาน
- Trigger Main/Sub แสดง configuration ที่เว็บอ้างถึง; ตรวจประวัติการเปลี่ยนชุดและช่วง Rank Wars เพิ่มเมื่อเขียนฉากเฉพาะ
- ค่า Trion ในไฟล์นี้ยังลงเฉพาะรายที่ระบุชัด; ช่องว่างไม่ใช่ 0. **อันดับทีม A/B มีเวลาอ้างอิง** ไม่ควรใช้เป็นอันดับในโลกอนาคต
- **Side Effect** เป็นคุณสมบัติแยกต่างหากจาก Trigger; ไม่ให้สมมติว่าทุก agent มี Side Effect
- `S-rank` ในระบบ Border ของต้นฉบับผูกกับ **การใช้ Black Trigger เป็น Trigger หลัก**: https://worldtrigger.fandom.com/wiki/Trigger จึงต้องระบุใน continuity ของนิยายว่าคุกะเป็นระดับ S ด้วยเหตุผล/Trigger แบบใดหลังหายเป็นมนุษย์; ตอนนี้คำอธิบายนั้น UNKNOWN
- ตัวเอกใหม่ยังไม่มี Rank, Trigger, Trion, Side Effect และตำแหน่ง จนกว่าผู้เขียนกำหนด
