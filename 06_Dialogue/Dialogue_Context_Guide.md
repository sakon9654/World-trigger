# Dialogue context
ก่อนเขียนบทสนทนา ต้องระบุ scene ID, story time, POV, participants, relationship as-of, character voice, knowledge as-of และเป้าหมาย/ความลับของผู้พูด
สำหรับตัวเอกใหม่ ห้ามสมมติว่ารู้จักหรือรู้ความลับของตัวละครเดิม หากยังไม่มี event ที่เชื่อม
ประโยคที่ตัวละครพูดเป็นความเชื่อ/โกหกได้ ไม่เท่ากับ objective canon
