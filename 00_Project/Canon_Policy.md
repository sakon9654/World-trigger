# Canon tiers และสถานะ
- `source_canon`: เนื้อหาต้นฉบับที่ตรวจสอบได้ก่อน [[Canon_Cutoff]]
- `hypothetical_ending`: เรื่องที่ผู้เขียนแต่งเพิ่มจาก cutoff จนถึง T0
- `future_continuity`: เหตุการณ์หลัง T0 รวมทั้งสถานะตัวละครเดิม
- `original_fiction`: ตัวเอกใหม่และสิ่งสร้างสรรค์ใหม่
สถานะใช้ `draft`, `proposed`, `approved`, `locked`, `deprecated`

กฎ: อย่าอ้างตอนจบสมมติเป็นข้อเท็จจริงของมังงะ; อย่าผูกสถานะ S-rank ของคุกะเข้ากับทีม B ประจำ; ถ้าข้อมูลยังไม่กำหนดให้เขียน UNKNOWN; source canon ใหม่หลัง cutoff ไม่แทนที่ความตกลงผู้เขียนอัตโนมัติ
