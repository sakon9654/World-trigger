# Canon Cutoff
อ้างอิง **จุดเหตุการณ์ที่ผู้เขียนระบุ** ไม่ควรเดาเลข chapter จนกว่าจะตรวจจากต้นฉบับจริง

หลังจุดนี้คือ [[Hypothetical_Ending]] ซึ่งเป็นเนื้อเรื่องสมมติของโปรเจกต์
