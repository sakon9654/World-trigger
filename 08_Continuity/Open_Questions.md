## ไม่จำเป็นต้องตอบทันที
- [ ] บุคคลสำคัญที่ช่วยกลับมาเป็นใคร / จำนวนคน / ได้กลับมาพบใคร
- [ ] ภารกิจเกิดที่ดาวเนเบอร์ไหน ดำเนินการอย่างไร
- [ ] กลไกและผลข้างเคียงการรักษาคุกะ; Side Effect เดิมยังอยู่หรือไม่
- [ ] ตำแหน่ง/ภารกิจ S-rank ของคุกะในชีวิตประจำวัน
- [ ] โอซามุเพิ่ม Trion ได้อย่างไรและมีค่าเท่าใด
- [ ] จุดเปลี่ยนความคิดของจิกะจนยิงคนได้
- [ ] ฮิวส์ตั้งรกรากเมื่อไรและปรับตัวอย่างไร
- [ ] ปีและวันที่เกิดพัฒนาการของแต่ละคน
- [ ] ชื่อ อายุของ OC; เหตุผลสมัคร Border และภูมิหลังละเอียด; ชื่อทีมและ Operator
- [ ] ชื่อ/บุคลิก/ค่า Trion Sniper เพื่อนหญิง: มีข้อเสนอแต่ยังไม่ล็อก
- [ ] รายละเอียดขอบเขตการมองวิถีกระสุน Bullet Line และฉากค้นพบ
- [ ] ตัวละครไหนรู้ความลับภารกิจเนเบอร์ ณ วันเปิดเรื่อง
