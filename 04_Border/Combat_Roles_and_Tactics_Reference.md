# World Trigger — วิธีสู้ตามตำแหน่งและคู่มือวางฉาก Rank Wars

> ขอบเขต: อิงรูปแบบที่มีหลักฐานจากมังงะถึงบท 196, BBF และข้อมูลอ้างอิงตำแหน่ง/Trigger; **ตัวอย่างแท็กติกและแม่แบบฉากเป็นข้อเสนอเพื่อเขียนแฟนฟิก** ไม่ใช่คำกล่าวว่าตัวละคร Canon ทุกคนทำเหมือนกัน. เน้นข้อจำกัดเรื่องตำแหน่ง การเคลื่อนที่ ข้อมูล และการเข้าถึงระยะ.

## สรุปหลักการที่ใช้กับทุกตำแหน่ง
1. ผู้ชนะการปะทะไม่ใช่คนที่ตัวเลขโจมตีสูงสุดเสมอ: **มุมยิง ระยะ ที่กำบัง การมองเห็น Trigger ฝ่ายตรงข้าม เพื่อนร่วมทีม และเวลา** มีผล.
2. ต้องแยก **ฆ่า/ทำลายคู่ต่อสู้, ยิงกดเพื่อสร้างโอกาส, ซื้อเวลา, บังคับทิศทาง, คุมพื้นที่, เก็บข้อมูล, ถอนตัว** เป็นเป้าหมายต่างกัน.
3. ทุกการเคลื่อนที่ควรมีเหตุ: เข้าระยะถนัด, ย้ายมุมยิง, รักษาที่กำบัง, รวมทีม, ป้องกัน Sniper หรือหลบ Attacker. อย่าให้ศัตรูยืนรอถูกยิง.
4. **Shield เป็นสีเขียวตามกฎโปรเจกต์**; กางกว้างป้องกันหลายทิศแต่ทนกระสุนหนักต่อจุดได้น้อยกว่าการรวม Shield เฉพาะจุด. ผลการยิงไม่รับประกันเจาะทุก Trion/ทุก Shield.
5. ความสำเร็จของทีมมาจากข้อมูลที่สื่อสารทัน: Operator ไม่เห็นศัตรูที่ Bagworm ซ่อนอยู่บนเรดาร์มาตรฐาน; ดู [[Operator_Screens_Radar_and_Information_Limits]].
6. กลไก Trigger สลับเปิดได้ตามฝั่ง Main/Sub: ห้ามเปิด Trigger สองช่องในฝั่งเดียวพร้อมกันโดยไม่มีความสามารถเฉพาะ. **Full Attack = ทุ่มสองฝั่งเพื่อโจมตีและมักเสียโอกาสใช้ Shield ตามปกติในจังหวะนั้น**; พิจารณาตำแหน่งในสล็อตเสมอ.
7. ในร้อยแก้วให้สื่อว่า "เข้าระยะ/ถอยพ้นระยะ/คุมมุมยิง" มากกว่าบอกเมตรเป๊ะ ๆ; ถ้าต้องระบุตัวเลขระหว่างเกมให้เป็นบทพูดผู้บรรยายเกม ตาม [[OC-Trio-Dialogue-Samples]].

## 1. Attacker — สายประชิด (Kogetsu / Scorpion / Raygust)

**งานในทีม**
- ลดระยะให้เข้าถึงตัว, ทำลายแนวป้องกัน, บีบบังคับคู่ต่อสู้ให้หยุดยิงหรือหัน Shield, ปิดทางหนี, เป็นแนวหน้า/ตัวล่อที่สร้างแรงกดดันให้พลพรรคอื่น.
- Attacker หลายคนใช้ **Shield ระหว่างเข้าระยะ**, การใช้สิ่งกีดขวาง/Grasshopper หรือเดินอ้อมมุมตึก. **ไม่จำเป็นต้องวิ่งตรงกลางถนนรับกระสุน**.
- ภายในระยะประชิดสามารถสร้างความเสียหายต่อเนื่องได้สูงโดยใช้ Trion ต่อการฟันน้อยเมื่อเทียบกับการยิง.

**รูปแบบแตกต่าง**
- **Kogetsu:** ความแข็งแรง/ความทนทานของดาบ; รักษาไลน์ปะทะ; Senkū ยืดคมดาบโจมตีชั่วคราวได้ — ไม่ใช่ทุกคนมีระยะและความเร็วเหมือนอิโคมะ.
- **Scorpion:** คล่อง เปลี่ยนรูปร่างโจมตีมุมแปลก/จากส่วนของร่าง; ต้องคิดแลกความยืดหยุ่นกับความทนทาน.
- **Raygust:** ยืดหยุ่นระหว่างดาบ/Shield mode; ใช้ป้องกันและ Thruster เพื่อโจมตี/เคลื่อนที่เมื่อมีติดตั้ง.

**เกมแก้ทางและการเล่า**
- Attacker ชนะ Gunner/Shooter หากเข้าถึงตัวก่อนโดนกดหรือถูกบังคับทาง; Gunner ที่ยิงแม่นอาจต้องเลือกหนี/ยิงสกัด ไม่ใช่ยิงจนชนะทุกครั้ง.
- **สำหรับเร็น:** พยายามคงระยะ Control/Finisher, ยิงกดทางที่ Attacker ต้องผ่าน, ถอยเฉียง/ใช้ที่กำบัง, เรียกมิโอะสกัดแนวเข้าใกล้; ถ้า Attacker ที่เก่งเข้าถึงระยะฟัน เร็นเสียเปรียบชัดเจน.
- ตัวอย่างจังหวะ: Attacker ยก Shield บังการยิง Control และสไลด์เข้าระยะ, เร็นต้องเลือกระหว่างถอยรักษาระยะกับเสี่ยง Finisher หนึ่งนัด.

**ห้ามเขียน:** Attacker ยืนหันหน้าเดินรับปืนโดยไม่พยายามหลบ/ป้องกัน; Senkū เท่ากับไกลไม่จำกัด; ความเร็วสูงแปลว่าไม่มีค่าใช้ Trion.

## 2. Gunner — ยิงผ่านปืน (Asteroid/Hound/Viper/Meteor ตามอุปกรณ์)

**งานในทีม**
- **ควบคุมพื้นที่และพฤติกรรมศัตรู** ด้วยกระสุนต่อเนื่อง: บีบให้ Shield อยู่ทิศหนึ่ง, ปิดทางเดิน, กดให้ศัตรูติดที่กำบัง, เปิดมุมให้เพื่อนร่วมทีม.
- ปืน Trigger ให้ **ระยะยิงเพิ่มประมาณ 20% เมื่อเทียบกับกระสุนตั้งค่าแบบ Shooter ที่เทียบเคียงกัน** (คำอธิบายของคาราสึมะ), แลกกับการตั้งค่ารูปแบบกระสุนที่ไม่ยืดหยุ่นขณะยิงเท่า Shooter.
- ปืนลูกซอง/ปืนสั้น/ปืนยาวต่างบทบาทจริง: ระยะ อัตราการยิงและความรุนแรงของชุดกระสุนต้องสัมพันธ์กับรูปแบบอาวุธ; อย่าให้มือปืนทุกคนยืนห่างเท่ากัน.
- การ **ยิงพร้อมกันหลายคน / โฟกัสเป้าหมาย** ช่วยบีบ Shield หรือบังคับพื้นที่ แต่ต้องระวังมุมยิงขัดกันเองและความเปลือง Trion.

**วิธีสู้ในฉาก**
- ยิงกดทางออกหนึ่งเพื่อให้อีกคนวิ่งอ้อม, เก็บจังหวะรีโหลด, โยนแรงกดดันให้ศัตรูยก Shield แล้วเพื่อน Attacker เข้าฟัน.
- Gunner หลายคนถนัดยิงต่อเนื่องกว่าการเลือกนัดเดียว; ฝีมือแสดงที่การวางตำแหน่ง ไม่ใช่ต้องยิงโดนทุกนัด.
- **Control เร็น: 26 นัด พลัง 6/10 ระยะยิงสูงสุด 60 ม.** เป็นปืนอเนกประสงค์สำหรับยิงสู้/กดดัน/เปลี่ยนมุม; ภายในระยะถนัดกระสุนเร็วและแรง.
- **Finisher เร็น: 10 นัด พลัง 10/10 ระยะสูงสุด 30 ม.** ใช้ปิดจังหวะระยะใกล้ มีต้นทุน Trion ต่อนัดสูงกว่า; ไม่ใช่ปืนที่รัวได้แบบ Control. ไม่แปลว่าทะลุ Shield ทุกคน.

**เกมแก้ทาง**
- สู้อีก Gunner ต้องคิดว่าใครมีกำบัง ระยะกระสุน ใครต้องรีโหลดก่อน ใครถูกบังคับเปลี่ยนทาง; ไม่ใช่ดวล DPS ล้วน.
- สู้ Shooter ต้องหลบเส้นทางกระสุนที่เปลี่ยนได้และระวังการแบ่ง/ตั้งรูปกระสุน; สู้ Sniper ต้องไม่เปิดพื้นที่โล่ง.

## 3. Shooter — ใช้ก้อน Trion โดยไม่มีปืน

**งานในทีม**
- **จัดรูปแบบกระสุนและมุมยิง** ปรับสมดุล **พลัง/ความเร็ว/ระยะ** ตามการแบ่งก้อนก่อนยิง; กระสุนมากชิ้นโดยทั่วไปเล็กลงต่อชิ้น จึงต้องวางแผนว่าจะหวังเจาะหรือหวังกด.
- ยิงจากมุมไม่เหมือน Gunner ปกติ: ปล่อยก้อนจากตำแหน่งต่างกัน, แบ่งชุดและใช้จังหวะหลอก Shield, สร้างเส้นทางยิงซับซ้อน.
- ต้องมีเวลา/ทักษะในการตั้งค่า เปลี่ยนชนิด กระสุนแยกและควบคุมความแม่น; Shooter ไม่ได้ยิงทุกนัดเร็วกว่ามือปืนในทุกสถานการณ์.

**ชนิดกระสุน**
- **Asteroid:** วิถีตรง ธรรมดาแต่มีพลังโจมตีพื้นฐานสูง เหมาะรวมยิง/เจาะจุด.
- **Hound:** กระสุนติดตามเป้าตามระบบติดตามและค่าที่ตั้ง (ไม่ใช่ยิงแล้วหักเลี้ยวตามใจได้ไร้ขอบเขต); ใช้บังคับทิศหลบและโจมตีมุม.
- **Viper:** ตั้งเส้นทางหักเลี้ยวเป็นลำดับ; คนเก่งบางคนเปลี่ยนวิถีแบบเรียลไทม์ได้ แต่ **ห้ามให้ทุก Shooter ทำโดยง่าย**.
- **Meteor:** พื้นที่ระเบิด/ทำลายที่กำบัง/ปิดเส้นทาง; มีความเสี่ยงกับพื้นที่และจังหวะใช้.
- **Composite Bullets** เช่น Gimlet, Tomahawk, Hornet, Salamander เป็นการผสมเฉพาะที่มีเงื่อนไขและต้องใช้ความชำนาญ; อย่าให้มีทุกแบบทันที.

**ฉากน่าใช้**
- Shooter เปิดก้อนหนึ่งด้านซ้ายเพื่อดึง Shield จากนั้นปล่อยอีกชุดมุมอื่น; อีกฝ่ายเลือกหนี/กระโดดหลบแทนยืนรับ.
- Shooter ยิงให้ศัตรูต้องเลือกเดินซอยที่ซ่อน Spider / Attacker รออยู่ (หากทีมมี Trigger/ตัวละครใช้จริง).
- **สำหรับเร็น:** Gunner ที่บังคับมุมได้ดีอาจแลกยิงกับ Shooter กลางสนามได้ แต่ต้องระวัง Shooter ข้ามที่กำบังหรือยิงเลี้ยว; เปลี่ยนตำแหน่งก่อนโดนปิดเส้นทาง.

## 4. Sniper — ระยะไกล (Egret / Lightning / Ibis)

**งานในทีม**
- ซ่อนตำแหน่ง รอเวลาที่เป้าเปิดตัว, คุมเส้นยิงจากระยะไกล, บังคับให้ศัตรูไม่กล้าเดินผ่านจุดเปิด, เก็บข้อมูลภาพรวมด้วยสายตา/การรายงาน.
- **Bagworm** ช่วยซ่อนสัญญาณบนเรดาร์แต่ต้องใช้ Trion ต่อเนื่อง; ไม่ได้ทำให้ตัวล่องหนต่อสายตา.
- ปืน Sniper โดยทั่วไปมีอัตรายิงต่ำกว่า Gunner; หลังยิงมักเปิดตำแหน่งด้วยเสียง/แสง/แนวกระสุน และต้อง **เปลี่ยนที่ทันที** หากถูกระบุตำแหน่ง.
- **Egret:** อเนกประสงค์ เน้นระยะและความสมดุล; **Lightning:** เร็วและเบา แต่ต่อช็อตเบากว่า; **Ibis:** พลังทำลายสูง โดยทั่วไปกระสุนช้ากว่า.
- Sniper คุมพื้นที่ได้แม้ไม่ยิง หากศัตรูรู้หรือคาดว่ามีแนวยิงคุมอยู่; ให้แสดงการหยุด/เลี่ยงมุมยิงโดยไม่จำเป็นต้องลั่นไก.

**เกมแก้ทาง/ข้อเสียเปรียบ**
- Sniper ไม่ควรชนะการดวลประชิดเป็นเรื่องปกติ; เมื่อถูกเข้าใกล้ต้องหนี ย้ายตำแหน่ง เรียกเพื่อนคุ้มกัน หรือใช้ Shield/อุปกรณ์ที่มี.
- หลายครั้งตัว Sniper ต้องตัดสินใจว่า **เก็บตำแหน่งลับไว้เพื่อเก็บเป้าที่คุ้มค่า** หรือยิงช่วยเพื่อนทันทีแล้วถูกตามตัว.
- **สำหรับมิโอะ:** หามุมที่คุมทางถอยและทางเข้าของ Attacker, รับข้อมูลจากเร็น, อย่าเปิดตัวหากความเสี่ยงสูง; การยิงช่วยเร็นอาจทำให้ศัตรูรู้ตำแหน่งและบังคับให้เธอต้องย้าย. ชนิดปืนจริงของมิโอะยังไม่ล็อก อย่าอนุมานว่ามีทั้งสามแบบ.

## 5. All-Rounder — ผสมสายประชิดกับยิงปืน

- ใน Canon นิยามตำแหน่งจาก **Attacker Trigger และ Gunner Trigger ที่ได้คะแนน Solo อย่างน้อยด้านละ 6,000 คะแนน**; ไม่ใช่เพียงใส่ปืนกับดาบแล้วได้รับตำแหน่งทันที.
- สลับบทบาทตามระยะ: เริ่มยิงกดให้ฝ่ายตรงข้ามกาง Shield, เมื่อเข้าระยะที่เหมาะจึงเข้าฟัน; หรือหนีประชิดแล้วสลับยิง.
- หลอกให้คู่ต่อสู้เตรียมรับปืน แล้วเปลี่ยนเป็นดาบ; แต่ทุกจังหวะสลับ Trigger ต้องเคารพสล็อตและการป้องกัน.
- จุดแข็งคือไม่แพ้ระยะเดียวชัดเจน; จุดที่ควรเขียนคือการวัดระยะและอ่านว่าควรสลับเมื่อไร ไม่ใช่ชนะทุกสถานการณ์.
- **สำหรับเร็น:** ต้องเฝ้าดูว่าคู่ต่อสู้กำลังเปลี่ยนจากปืนเป็นดาบหรือใช้ตัวล่อบีบให้เข้าใกล้.

## 6. Trapper — สนับสนุนด้วยกับดักและการย้ายตำแหน่ง

- อุปกรณ์ตัวอย่าง **Switchbox** ใช้เครื่องหมายกับดักในแผนที่; มีทั้งกับดักสร้างความเสียหายและ **Short Warp** ช่วยเคลื่อนย้ายพันธมิตร.
- ความเก่งเกิดจาก **เตรียมพื้นที่ วางเงื่อนไข และทำให้ฝ่ายตรงข้ามเดินเข้าทางเลือกที่ไม่ดี**; ไม่ใช่ต้องโจมตีด้วยตัวเอง.
- ตัวอย่างการเล่า: Gunner กดยิงบังคับศัตรูผ่านถนนแคบ → กับดักทำงาน / เพื่อนถูกเคลื่อนที่ไปยังจุดคุ้มกัน.
- Switchbox มีความซับซ้อนและ Trion cost; เครื่องหมายบางรูปแบบปรากฏเป็นสัญญาณบนเรดาร์ได้; ไม่ให้กับดักไร้ข้อเสียทุกชนิด.
- ตำแหน่งนี้เฉพาะทางและพบไม่บ่อย: ห้ามสมมติว่าทีม B ทั่วไปทุกทีมมี Trapper.

## 7. Spotter — ผู้ตรวจจับ/สังเกตการณ์ (ข้อมูล Canon จำกัด)

- มีตำแหน่ง **Spotter** และตัวอย่างผู้ใช้ **Enhanced Radar** แต่กลไกและเงื่อนไขตำแหน่งยังมีข้อมูลจำกัดในช่วงต้นฉบับที่ใช้.
- เล่าอย่างระมัดระวัง: ช่วยเสาะข้อมูลหรือรักษาภาพรวมให้ทีมตาม Trigger ที่พิสูจน์ว่าติดตั้งจริง; **ห้ามอ้างเป็นมาตรฐานว่าเห็นทุกจุดแม้ใช้ Bagworm หรือว่าเป็น Sniper ประเภทหนึ่ง**.
- ถ้าตัวละครตำแหน่งนี้จะลงสนาม ต้องตรวจ loadout และบทที่ปรากฏก่อนออกแบบความสามารถเฉพาะ.

## 8. Operator — สนับสนุนข้อมูล ไม่ใช่นักสู้คนที่สาม

- สังเกตเรดาร์/ข้อมูลแผนที่, สถานะสมาชิก, รายงานที่ตรวจยืนยัน, จุดที่ควรระวัง และแผนเปลี่ยนตำแหน่ง; **ส่งแท็ก/เส้นทาง/คำเตือนเข้า Field of View สมาชิก**.
- ฝีมือคือ **คัดข้อมูลที่ควรพูดในเสี้ยววินาที** ไม่ใช่ให้คนในสนามฟังรายงานยาว ๆ หรือทราบตำแหน่งศัตรูที่ซ่อนทั้งหมด.
- หากศัตรูเปิด **Bagworm** จุดบนเรดาร์มาตรฐานหาย; ถ้า **Chameleon** จุดยังอยู่; การคาดการณ์ตำแหน่งต้องมีหลักฐานอื่น.
- **ลูน่า:** นอกสนามขี้เล่น; เมื่อคุมเกมต้องสั่งสั้นทันเวลา; รักษาความต่างระหว่าง **ยืนยัน / ตำแหน่งล่าสุด / คาดว่า / ไม่ทราบ**, และอย่ารู้ Side Effect Bullet Line ก่อนเปิดเผยในโครงเรื่อง.
- ดูรายละเอียดหน้าจอ [[Operator_Screens_Radar_and_Information_Limits]].

## 9. คู่ปะทะและข้อได้เปรียบแบบสถานการณ์ (แม่แบบการเขียน ไม่ใช่กฎชนะอัตโนมัติ)

| คู่ปะทะ | ฝ่ายไหนได้เปรียบเมื่อใด | จุดพลิกเกมที่ควรเล่า |
|---|---|---|
| Attacker vs Gunner | Attacker ถ้าเข้าใกล้โดยไม่เสียท่า; Gunner หากรักษาระยะและบังคับเส้นทาง | ทางเข้าหลังมุมตึก, Shield, การวิ่งตัดมุมและเพื่อนคุ้มกัน |
| Attacker vs Shooter | Shooter มีพื้นที่สร้างรูปกระสุน; Attacker เข้าเร็วไม่ให้จัดรูป | กระสุนเปลี่ยนวิถีกับการเข้าฟัน/หลบผ่านอาคาร |
| Gunner vs Shooter | Gunner ยิงเสถียร/ต่อเนื่อง; Shooter ปรับรูปและมุมยิง | ใครต้องหลบก่อน, กระสุนจากมุมอับ, ระยะและเวลาสร้างกระสุน |
| Gunner vs Gunner | ขึ้นกับระยะปืน, ความหนาแน่นกระสุน, ที่กำบังและการรีโหลด | ย้ายมุมกับการสลับ Shield; ยิงกดเพื่อซื้อเวลา |
| Sniper vs ทุกสาย | Sniper ชนะจังหวะที่ไม่ถูกเห็นและมีแนวยิง; แพ้ความเสี่ยงเมื่อถูกตามถึงตัว | การเปิดตัวหลังยิง, Bagworm, การหนีและจุดซุ่มสำรอง |
| All-Rounder vs Gunner | All-Rounder บีบระยะให้สลับเข้าฟันได้; Gunner รักษาระยะถนัด | จังหวะปลด/เปลี่ยน Trigger และการเปิด Shield |
| Operator vs ข้อมูลไม่ครบ | ทำให้ทีมตัดสินใจได้ดีขึ้นเมื่อระบุความไม่แน่นอน | ข้อมูลล่าช้า/Bagworm/ตำแหน่งสุดท้าย/การรายงานสมาชิก |

## 10. เช็กลิสต์ก่อนเขียนหนึ่งฉากสู้
1. ทุกฝ่ายเริ่มอยู่ที่ไหน **รู้ตำแหน่งฝ่ายตรงข้ามจากอะไร**? มี Bagworm / Chameleon / สิ่งกีดขวางหรือไม่?
2. เป้าหมายของแต่ละฝ่ายคือเก็บคะแนน **หรือ** ซื้อเวลา บังคับศัตรูเข้าทางปืนเพื่อน ปกป้อง Sniper หรือหนี?
3. จุดไหนเป็น **ระยะถนัด / ระยะเสี่ยง / พ้นระยะ** ของ Trigger คนนั้น?
4. ใครกำลังเปิดสล็อต Main/Sub ใด? ใครต้องพักปืน/ดาบก่อนใช้ Shield หรือ Trigger อื่น?
5. การยิงบังคับการเคลื่อนไหวอย่างไร? Shield ไหนกางกว้างหรือรวมเฉพาะจุด? มีค่า Trion ใช้ไปหรือไม่?
6. Sniper เปิดตำแหน่งด้วยการยิงหรือยัง? มีแผนย้ายจุด/ทางหนีหรือไม่?
7. Operator รู้เหตุการณ์จาก **เรดาร์ รายงาน หรือการคาดการณ์**? คำสั่งส่งทันหรือช้า? เพื่อนร่วมทีมทำตามหรือไม่?
8. เมื่อยิงไม่โดน **ยังได้ประโยชน์ด้านยุทธวิธีไหม** เช่น บีบมุม/ตัดทาง/เปิดที่ให้มิโอะยิง?
9. ฝ่ายที่ถูกกดดันตอบโต้มีเหตุผลไหม ไม่ใช่หยุดนิ่งให้ฝ่ายเอกชนยิง?
10. จบฉากต้องเหลือผลให้ต่อยอด: เสียตำแหน่ง, เสียแขน, ถูกเปิดเผยจุดซุ่ม, ต้องรีโหลด/พัก Trion, หรือเปลี่ยนแผน.

## 11. วิธีนำมาใช้กับทีมซาเอกิโดยเฉพาะ
- **เร็น (Gunner):** Control 60m / Finisher 30m เป็นระยะยิงสูงสุดที่ล็อกแล้ว; ใช้ Control เปิด/กด/แลกยิง กับ Finisher ปิดโอกาสใกล้; Run & Gun ดีแต่ยังแพ้ Attacker ที่เข้าถึงตัวหรือ Sniper ที่ซ่อนอยู่.
- **มิโอะ (Sniper):** สร้างความกลัวจากแนวยิงและระวังเปิดตัว; ช่วยเร็นได้เมื่อมุมถึงเท่านั้น; ไม่ใช่ตำแหน่งใดก็ช่วยยิงผ่านอาคารได้.
- **ลูน่า (Operator):** อ่านตำแหน่งที่ยืนยันได้, เตือนความเสี่ยง, ส่งข้อมูลที่จำเป็น, คุมจังหวะทีม; คนอ่านต้องสัมผัสฝีมือเธอจากการเลือกข้อมูลและสั่งการแม้ข้อมูลไม่ครบ.
- สถานการณ์ที่ทีมควรชนะ: เร็นกดให้ศัตรูเคลื่อนเข้าแนวมิโอะ, ลูน่ามองเห็นทางเลือกและคุมเวลา.
- สถานการณ์ที่ทีมควรพลาด: เร็นไล่ยิงเกินพื้นที่ที่มิโอะช่วยได้, ศัตรูอาศัย Bagworm/อาคารกั้นการมองเห็น, Attacker บังคับประชิดโดยอีกฝ่ายช่วยไม่ทัน.
- **ตอนที่ 6** เป็นฝึกการฟังคำสั่ง: เร็นยิงเป้าได้แต่เสียตำแหน่ง จึงเรียนรู้การรอให้ทีมพร้อม; ตอนที่ 7 ให้สถานการณ์หลายเป้าบีบให้รายงานทันเวลาโดยไม่ทำลายความเก่ง Operator.
