# Bullet Line — Side Effect แฝงของพระเอก

## สิ่งที่ผู้เขียนกำหนดแล้ว
- พระเอก **มี Side Effect** แต่ **ยังไม่รู้ตัวในฉากเปิดเรื่อง**.
- **Bullet Line** เป็น Side Effect เกี่ยวกับ **การรับรู้วิถีกระสุน/แนวยิง** จึงช่วยให้เขายิงได้แม่นยำแม้ยกปืนเล็งเพียงพริบตา โดยเฉพาะเมื่อวิ่ง เปลี่ยนมุม และยิงแบบ Run & Gun; ผู้เขียนยืนยันแกนความสามารถนี้แล้ว
- **หลังจากเขาใช้ Hound** เขาและคนรอบข้างจึงค่อยค้นพบว่าเขามี Side Effect; ไม่ใช่การเพิ่งได้รับพลังจาก Hound.
- Motion Resolution แบบเก่า **ถูกแทนที่** โดยแนวคิด Bullet Line.

## แกนความสามารถที่ล็อกแล้ว
- **เห็นหรือรับรู้แนววิถีกระสุนของตัวเองอย่างรวดเร็วระหว่างตั้งแนวยิง** ทำให้กะมุมและลั่นไกได้ทันทีโดยไม่ต้องเล็งค้างนาน
- **เหมาะกับ Run & Gun:** วิ่ง เปลี่ยนมุม ยกปืนเพียงชั่วพริบตา แล้วเลือกแนวยิงได้แม่นยำ; ไม่ใช่การเพิ่มอัตราเคลื่อนที่หรือความเร็วกระสุน
- ความสามารถช่วยเรื่องการกะวิถี **ไม่รับประกันกระสุนโดน** เมื่อเป้าหมายหลบ เปลี่ยนทาง หรือใช้ Shield และไม่ชดเชยทักษะทีม

## รายละเอียดเสริมที่ยังเป็นข้อเสนอ
- เห็นเส้นแนวยิงของกระสุนที่เขาเตรียมจะยิง โดยเฉพาะ Asteroid ที่วิ่งตรง.
- เส้นของ Hound ปรากฏเป็นแนวโค้งที่เปลี่ยนตามวิธีติดตามเป้า/ค่าการเลี้ยว เป็นจุดที่ทำให้เขารู้ว่าตัวเองรับรู้บางอย่างมากกว่าการคาดคะเนแบบกีฬา.
- อาจมองแนวกระสุนศัตรูที่มองเห็นจริงแล้วได้ แต่ **ไม่ตรวจพบตำแหน่ง Sniper ที่ซ่อนอยู่**.
- เส้นเป็นแนวความเป็นไปได้/วิถีตามข้อมูลขณะนั้น **ไม่รับประกันว่าจะยิงโดนศัตรูที่เปลี่ยนทิศหรือยก Shield**; ไม่ใช่การเห็นอนาคตแบบ Jin.
- ไม่เพิ่ม Trion, ความเร็วร่างกาย, ความชำนาญ Hound หรือ Grasshopper อัตโนมัติ.

## ลำดับการเปิดเผยที่เสนอ
1. ช่วงแข่งขันเดี่ยว เขายิงแม่นด้วยการอ่านแนวที่เห็น แต่คิดว่าเป็นเซนส์การยิงจากกีฬา BB Gun.
2. ช่วงฝึก Hound หลังตั้งทีม เริ่มเห็นแนวกระสุนที่โค้งและแปรไปตามการตั้งค่า จึงสับสน.
3. คนอื่นสังเกตว่าเขาอธิบายแนวกระสุนได้แม้ยังควบคุม Hound ไม่คล่อง จึงมีการทดลองเปรียบเทียบ.
4. **จึงเริ่มรู้พร้อมกันว่าอาจเป็น Side Effect** และค่อยพิสูจน์กลไก — ตอน/ผู้เข้าร่วมการค้นพบยังไม่กำหนด.

## ข้อจำกัดที่ต้องรักษา
- ยังแพ้ทาง **Sniper ที่ซ่อนอยู่ในพื้นที่เปิด**: วิถีที่เห็นไม่ได้ทำให้รู้จุดยิงก่อนมีสัญญาณให้รับรู้ และอาจตอบสนองไม่ทัน.
- ยังเสียเปรียบ **Attacker ฝีมือสูง** ที่เข้าประชิด: เห็นแนวการยิงไม่ได้เพิ่มทักษะต่อสู้ประชิด.
- การเข้าใจแนวยิงไม่แทนการอ่านเพื่อนร่วมทีมหรือการแจ้งข้อมูลให้ทีม; ปมไม่ยอมขอความช่วยเหลือยังอยู่.
- **ห้ามบรรยายให้ผู้อ่านรู้แน่ชัดตั้งแต่เปิดเรื่อง** หากฉากยังไม่ถึงจุดค้นพบตามแผน.
- ยังไม่ตัดสินว่าเห็นเส้นผ่านสิ่งกีดขวางได้หรือไม่, รับรู้วิถีของกระสุนฝ่ายตรงข้ามได้เพียงใด, และข้อจำกัดระยะ/ความล้า. แม้ยืนยันว่าใช้แนวยิงได้แทบฉับพลัน แต่รูปแบบภาพที่เจ้าตัวเห็นยังเปิดให้กำหนด.
