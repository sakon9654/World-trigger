# Operator — พี่สาวของ Sniper (ยังไม่ตั้งชื่อ)

## ข้อมูลที่ผู้เขียนยืนยัน
- เป็น **พี่สาวแท้ ๆ** ของ [[OC-SNIPER-FRIEND]] และรู้จัก [[OC-PROTAGONIST]] **มาตั้งแต่เด็ก**.
- ก่อนหน้านี้ไปเรียนต่างประเทศและ **เพิ่งกลับมา**; ประเทศและระยะเวลาเรียนยังไม่ได้ล็อก.
- ตอนพระเอกยังเด็ก พี่สาวชอบ **กอดและให้เขานั่งตัก** ด้วยความเอ็นดูแบบพี่สาวต่อเด็กที่รู้จักกัน ไม่มีนัยเชิงรักในช่วงวัยเด็ก.
- เมื่อพระเอกและน้องสาวคุยกันเรื่องตั้งทีม B-rank เธอ **บังเอิญได้ยินแล้วอาสาเป็น Operator** จากนั้นผ่านการสอบ/คัดเลือกด้วยความสามารถของตนเอง.
- **ทำหน้าที่ Operator ได้ยอดเยี่ยม** วิเคราะห์ ประสานข้อมูล และบัญชาการเก่งจริง แม้บุคลิกส่วนตัวจะขี้เล่น.
- บุคลิก **อาเจ๊สาวแซ่บ มั่นใจ ขี้แกล้ง ปากกล้า** ชอบแหย่พระเอกด้วยคำพูดสองแง่สองง่ามแบบคอมเมดี้ และทำให้น้องสาวต้องคอยปราม; หยุดเล่นเมื่อสถานการณ์จริงจัง.
- **ชอบวัฒนธรรมป๊อปญี่ปุ่นและคอสเพลย์แนวเซ็กซี่/โดดเด่น** เป็นความชอบด้านแฟชั่นและการแสดงออกของเธอ ไม่ใช่การแต่งกายทำงานที่ขัดระเบียบ Border.
- ทั้งสองพี่น้องมีภาพลักษณ์ **ลูกครึ่งญี่ปุ่นกับเชื้อสายยุโรปหรือ Latin** ตามคอนเซปต์ผู้เขียน; ตัวเลือกญี่ปุ่น–สเปนยังเป็น **ข้อเสนอ**.
- ความรู้สึกที่มีต่อพระเอก **เปิดให้ตีความได้ทั้งมิตรภาพ/เอ็นดู/โรแมนติก** โดยยังไม่กำหนดคู่รักและไม่ยืนยันการสารภาพรัก.

## บทบาทด้านความสัมพันธ์และการทำงาน
- นอกสนาม: ชอบใช้ความทรงจำตอนเด็กมาแซวพระเอกผู้สุภาพที่โตแล้ว; อารมณ์ขี้เล่นและมั่นใจ แต่เคารพขอบเขตในปัจจุบัน.
- กับน้องสาว: เถียงและหยอกกันตามประสาพี่น้อง; น้องสาวเป็นฝ่ายปรามเมื่อเธอแกล้งพระเอกมากไป แต่ทั้งคู่ห่วงกันจริง.
- ในสนาม: ออกคำสั่งชัดเจนและแม่นยำ มีความสามารถสูง; ความสามารถของเธอไม่ใช่เครื่องมือแก้ข้อเสียของพระเอกได้ทุกสถานการณ์ เพราะต้องอาศัยข้อมูลจริงที่เพื่อนรายงาน.
- ห้ามยืนยันว่าเธอรู้เรื่อง Bullet Line ก่อนเหตุการณ์หลังพระเอกใช้ Hound.

## ยังเป็นข้อเสนอ ไม่ใช่สิ่งที่ล็อก
- **อายุ 19 ปี**, Trion 3.
- ค่าประเมินเพื่อแต่งเรื่อง (ไม่ใช่ BBF ทางการ): Mechanical Operation 9, Data Analysis 9, Parallel Processing 8, Tactics 8, Command 9.
- สเปนเป็นประเทศที่ไปเรียน, นามสกุลและชื่อจริง, ทรงผม/ดวงตา, ประวัติสอบละเอียด และเหตุผลที่อยากเป็น Operator นอกเหนือจากการอาสาเมื่อได้ยินคุยกัน.
- ความชอบคอสเพลย์แบบเจาะจง เช่น ประเภทตัวละคร ชุดโปรด เทคนิคแต่งหน้า/ทำพร็อพ และการประกวด.
