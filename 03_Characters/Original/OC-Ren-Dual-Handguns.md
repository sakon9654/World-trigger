# อาโอกิ เร็น — ปืนคู่ Asteroid: Control / Finisher

## ค่าที่ผู้เขียนยืนยัน
- **Control (มือซ้าย, Main): 26 นัดต่อหนึ่งรอบรีโหลด; พลังทำลาย 6/10**
- **Finisher (มือขวา, Sub): 10 นัดต่อหนึ่งรอบรีโหลด; พลังทำลาย 10/10**
- ทั้งคู่เป็น **Asteroid Gunner แบบปืนพก** เน้นสไตล์ Run & Gun.
- เร็นมี **Trion 14** และ Solo Rank Wars บน Trigger หลัก **9,500 คะแนน**.
- **ระยะหวังผลสั้นกว่า Gunner ที่ใช้ปืนยาว/ปืนไรเฟิลทั่วไป** เพราะรูปแบบปืนพกและการตั้งค่าของเร็น **ไม่ใช่ปืนยิงไกล**.
- แต่ **ภายในระยะหวังผลของเขา** Trion สูงทำให้กระสุนมี **พลังทำลายและความเร็วกระสุนสูงมาก**. ต้องแสดงให้คู่ต่อสู้มีเวลาตอบสนองน้อยลงในระยะถนัด โดยไม่แปลงเป็นการยิงไกลเกินชนิดอาวุธ.
- คะแนนพลัง **6/10 และ 10/10 เป็นสเกลเปรียบเทียบอาวุธของเร็นในนิยาย** ไม่ใช่ค่าทางการ BBF, ไม่ใช่ระดับความเสียหายที่วัดเป็นตัวเลขสากล และ 10/10 ไม่รับประกันทะลุ Shield ทุกชนิด.

## รูปแบบการต่อสู้ที่ล็อก
- **Control:** กระสุนจำนวนมากกว่า ยิงแม่น รัวกว่า ใช้กดดัน สร้างทางเลือกบังคับสำหรับศัตรู และช่วยเร็นขยับมุมยิง; ด้วย Trion 14 แม้ชื่อ Control ก็มีความเร็วกระสุนและพลังต่อหนึ่งนัดสูงเมื่อเทียบกับปืนพกทั่วไปในระยะถนัด.
- **Finisher:** จำนวนกระสุนน้อยกว่า แต่กระสุนหนักกว่า Control มาก; ภายในระยะถนัดเป็นกระสุนนัดตัดสินที่ทั้งเร็วและแรง เหมาะกับโจมตีช่องว่างของ Shield, ปิดเกม หรือบังคับให้ฝ่ายตรงข้ามต้องตั้งรับจริงจัง; ไม่ใช่กระสุนที่ยิงได้ถี่เท่า Control.
- **ระยะใกล้–กลางที่ปืนพกมีประสิทธิภาพ:** เป็น **ช่วงการต่อสู้ที่เร็นได้เปรียบด้านพลังและความเร็วกระสุน** ไม่ใช่ระยะประชิดติดตัวกับ Attacker; ถ้า Attacker ฝีมือสูงเข้าถึงตัว เขายังเสียเปรียบ.
- **ระยะเกินจุดหวังผล:** ไม่อ้างว่าความเร็วหรือพลังสูงชดเชยการเสียระยะทั้งหมด; ระยะยิงไกลกว่าปืนยังเป็นข้อได้เปรียบของ Gunner ปืนยาวหรือ Sniper. ไม่แปลงเป็นปืนสไนเปอร์.
- **ข้อจำกัดการรับรู้:** ความแม่นจากทักษะและ Side Effect ที่ยังไม่รู้ตัวช่วยได้เฉพาะแนววิถีกระสุนที่เร็นมองเห็น/สนใจ ไม่ตรวจจับ Sniper ซ่อนตัวหรือแผนที่ทั้งหมด.

## ค่าสมดุลที่เสนอ (ยังไม่ล็อก; ใช้เพื่อทดลองเขียนฉาก)
| คุณสมบัติ | Control | Finisher |
|---|---|---|
| ความจุ | **26 นัด (ล็อก)** | **10 นัด (ล็อก)** |
| พลัง | **6/10 (ล็อก)** | **10/10 (ล็อก)** |
| ความเร็วกระสุนภายในระยะหวังผล | **9/10 (เสนอ)** | **9/10 (เสนอ)** |
| ระยะหวังผลเปรียบเทียบ Gunner ปืนยาว | **สั้นกว่า (ล็อก)** | **สั้นกว่า (ล็อก)** |
| ความถี่ในการยิง | **สูง** | **ต่ำกว่า Control** |
| เวลารีโหลดทดลอง | **1.8 วินาที (เสนอ)** | **3.0 วินาที (เสนอ)** |
| การใช้ Trion ต่อนัด | **น้อยกว่า Finisher** | **สูงกว่า Control มาก** |
| หน้าที่ | กดดัน/ควบคุมแนวเดิน/เปิดช่อง | เจาะช่องที่สร้างขึ้น/ยิงปิดจังหวะ |

**อย่าตีความ 9/10 เป็นค่าทางการ** และไม่อนุมานว่ากระสุนของสองกระบอกมีความเร็วเท่ากันในทุกสภาพ; ระดับ 9/10 เป็นเพียง shorthand ภายในแบบออกแบบ.

## วงจรรีโหลดและ Trion
- การรีโหลดเติมชุดกระสุน Trion ในปืน **ไม่ได้คืน Trion ที่ใช้ไปแล้ว**; เร็นมี Trion สูงแต่ไม่จำกัด. ต้องเหลือสำรองสำหรับ Shield และ Trigger อื่น.
- รีโหลด **Control** → Control หยุดยิงชั่วคราว; รีโหลด **Finisher** → Finisher หยุดยิงชั่วคราว. ใช้ปืนอีกฝั่งทดแทนได้เมื่อสล็อตฝั่งนั้นเปิดอยู่ แต่จะยิงด้วยปืนที่กำลังรีโหลดไม่ได้.
- Control อยู่ Main, Finisher อยู่ Sub ตามชุด Trigger ที่เสนอ; ต้องเคารพการเปิด Trigger **หนึ่งสล็อตต่อฝั่งในเวลาเดียวกัน**. Shield/Grasshopper/Hound จากฝั่งเดียวกันต้องพักปืนของฝั่งนั้นก่อน.
- การยิง Control จนหมด 26 นัดแล้วต่อ Finisher 10 นัด โดยไม่มีจังหวะรีโหลด/Trion tradeoff ไม่ควรเป็นรูปแบบยิงได้ไม่จำกัด.
- Shield ในฉากต่อสู้แสดงเป็น **สีเขียว** ตามกฎโปรเจกต์.

## ตัวอย่างเชิงยุทธวิธี
เร็นเข้ามาในระยะปืนพกที่ถนัด แล้วยิง Control 4 นัดจากมุมซ้ายอย่างรวดเร็ว คู่ต่อสู้จำเป็นต้องยก Shield สีเขียวตามแนวกระสุนที่มาเร็วผิดกว่าที่คาดไว้ เร็นจึงเปลี่ยนตำแหน่งยิงและปล่อย Finisher หนึ่งนัดใส่ช่องที่เปิดขึ้น กระสุนหนักและรวดเร็วทำให้ตั้ง Shield ใหม่ได้ยาก แต่ถ้าคู่ต่อสู้อ่านการเปลี่ยนมุมได้ล่วงหน้าหรือถอยออกนอกระยะหวังผล เร็นอาจเสียกระสุน Finisher ไปโดยไม่ได้แต้ม.

## สิ่งที่ยังไม่ล็อก
- เวลารีโหลดจริงของแต่ละกระบอก, ความเร็วการยิงเป็นวินาทีต่อนัด, ระยะเป็นเมตร, ต้นทุน Trion เป็นตัวเลข, ความเร็วกระสุนเป็นตัวเลขหรือความแตกต่างระหว่างสองกระบอก
- โครงรูปลักษณ์ปืน น้ำหนัก ระบบเล็ง และเงื่อนไขรีโหลดเชิงกล
- ค่าตัวเลขใด ๆ ที่ไม่ได้อยู่ในหัวข้อ 'ค่าที่ผู้เขียนยืนยัน' ข้างต้น
