# เพื่อนผู้หญิงของตัวเอก — Sniper

## ผู้เขียนยืนยัน
- เป็น **ผู้หญิง** และเป็น **เพื่อนของตัวเอกใหม่**
- ใช้ตำแหน่ง **Sniper**
- ตั้งทีม B-rank ใหม่ร่วมกับตัวเอกซึ่งเป็น Gunner คะแนนเดี่ยว 9,500
- เป็นหนึ่งใน **นักสู้สองคน** ของทีม; Operator เป็นอีกตำแหน่งหนึ่งที่ทีมต้องมี ไม่ใช่นักสู้

## สิ่งที่ยังไม่กำหนด
ชื่อ อายุ ค่า Trion, Trigger (Egret / Lightning / Ibis หรืออื่น ๆ), คะแนน Sniper, ประวัติการแข่งขันละเอียด, บทบาทหัวหน้าทีม และรายละเอียดเสื้อผ้าชิ้นโปรด

## ข้อควรระวัง
ยังไม่กำหนดว่าเป็นคู่รักหรือมีความรู้สึกโรแมนติก จึงให้เป็น **เพื่อน** ตามที่ผู้เขียนระบุเท่านั้น.

## แบบออกแบบเพิ่มเติม — proposed (ยังไม่ล็อกชื่อ)
**ชื่อชั่วคราวเดิม:** มิซึโนะ อาโออิ / Mizuno Aoi; **ยังไม่ยืนยันและต้องใช้นามสกุลเดียวกับพี่สาว** หากเป็นพี่น้องร่วมสายเลือดตามแบบที่ตกลงกัน
- Sniper เพื่อนหญิงของพระเอก; บุคลิกช่างสังเกต มีเหตุผล พูดตรง แต่ไม่ใช่คนชอบตำหนิ
- เชี่ยวชาญการเลือกตำแหน่งและมองภาพรวมของสนาม; กล้าถามเมื่อพระเอกไม่สื่อสาร
- จุดอ่อนคือการป้องกันตัวเมื่อถูกประชิด และอาจเสียจุดยิงที่ดีหากมัวช่วยเพื่อน
- **Trion ที่เสนอ 6**; Attack 6 / Defense-Support 6 / Mobility 5 / Skill 8 / Range 8 / Command 7 / Special Tactics 7 — ทั้งหมดเป็นค่าที่เสนอ
- **Loadout ที่เสนอ:** Main Egret, Lightning, Shield, empty; Sub Bagworm, Shield, empty, empty. ยังไม่ถือเป็น Trigger ที่ล็อก
- ความสัมพันธ์ที่เสนอ: เพื่อนที่รู้จักกันก่อนตั้งทีม แต่ไม่กำหนดว่ารู้จักตั้งแต่เมื่อใด ไม่สมมติว่าเป็นคู่รัก
- เธออาจมีส่วนสังเกตหรือทดลอง **Bullet Line** หลังพระเอกฝึก Hound แต่ยังไม่กำหนดว่าเธอเป็นคนค้นพบก่อนหรือไม่; ช่วงเริ่มเรื่อง **เธอไม่รู้ว่าเขามี Side Effect**
- เชื่อมกับ [[OC-Two-Person-Squad]] และ [[OC-Hidden-Side-Effect]]

## ความสัมพันธ์ครอบครัวและแฟชั่น — ผู้เขียนยืนยันล่าสุด
- เป็น **น้องสาวแท้ ๆ ของ [[OC-OPERATOR-OLDER-SISTER]]** และทั้งสองรู้จักพระเอกมาตั้งแต่เด็ก
- พี่สาวเคยไปเรียนต่างประเทศและเพิ่งกลับมา; ช่วงที่พี่ไม่อยู่ น้องสาวกับพระเอกยังรู้จัก/สนิทกันอยู่ (ช่วงเวลา/รายละเอียดกิจกรรมยังเป็นข้อเสนอ)
- พี่น้องมีคอนเซปต์ **ลูกครึ่งญี่ปุ่น–ยุโรปหรือ Latin**; ญี่ปุ่น–สเปนเป็นข้อเสนอ ไม่ใช่ข้อเท็จจริงที่ล็อก
- **ชอบญี่ปุ่นดั้งเดิมมาก** โดยเฉพาะเสื้อผ้าและสไตล์ญี่ปุ่นแบบดั้งเดิม แตกต่างจากพี่สาวซึ่งชอบคอสเพลย์เซ็กซี่/แฟชั่นโดดเด่น
- เป็นคนที่ **คอยปรามพี่สาว** เมื่อพี่แซวพระเอกสองแง่สองง่ามเกินไป
- บทหรือการกระทำของเธออาจชวนคิดว่ารู้สึกพิเศษต่อพระเอก แต่ **ไม่ยืนยันว่าเป็นความรัก** และไม่กำหนดคู่สุดท้าย

### ตัวอย่างแฟชั่นที่เสนอ (ยังไม่ล็อก)
กิโมโน ยูกาตะ ฮาโอริ เครื่องประดับหรือสีลายญี่ปุ่นดั้งเดิม; นิสัยช่างสังเกตและใจเย็นยังเป็นข้อเสนอรายละเอียดบุคลิก.
