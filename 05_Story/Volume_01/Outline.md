# ภาค 1 — กำแพงของผู้มีพรสวรรค์

## ฉากหลังที่ยืนยัน
โลกโดยรวมสงบสุขมา 4–5 ปีนับจาก [[Hypothetical_Ending]]. ดู [[Established_Cast]] สำหรับสถานะทีมโอซามุและคุกะ

## แกนเรื่องที่ผู้เขียนยืนยัน
- เริ่มด้วยชีวิตประจำวันของ **อาโอกิ เร็น, ซาเอกิ มิโอะ, ซาเอกิ ลูน่า** เพื่อให้รู้จักนิสัยทั้งสาม **ก่อน** คุยและลงมือตั้งทีม
- ลูน่าเพิ่งกลับจากเรียนต่างประเทศ รู้จักเร็นตั้งแต่เด็ก; เมื่อได้ยินเร็นกับมิโอะวางแผนตั้งทีม จึงอาสาเป็น Operator และสอบผ่านด้วยฝีมือ
- ทีมประกอบด้วย Gunner เร็น, Sniper มิโอะ และ Operator ลูน่า (ไม่ใช่นักสู้คนที่สาม)
- ฝึกจำลองแบบทีมกันเองก่อนลง Rank Wars จริง; เริ่มจาก **B กลุ่มล่าง**
- แข่งจริง **4–5 แมตช์ก่อนพบทีมโอซามุ**. ทีมเร็นชนะกลุ่มล่างต่อเนื่องและชนะบางทีมระดับกลางเพราะคู่ต่อสู้ไม่แข็งมากหรือสไตล์แพ้ทาง
- ต้นฤดูกาลทีมโอซามุอยู่บริเวณที่ถูกจับคู่พบกันได้เพราะ **โอซามุทดลองแผนใหม่**; ไม่ใช่จงใจอ่อนข้อหรือฝีมือตก
- **บอสท้ายภาค:** โอซามุเป็น Shooter สายควบคุมสนาม ใช้ทรัพยากรจำกัดได้น่ากลัวมาก; ฮิวส์เป็น Ace Attacker ดุดัน; จิกาใช้ Trion มหาศาลและยิงคนได้
- ทีมเร็น **พ่ายแพ้อย่างราบคาบ** และ **ภาคแรกจบทันทีด้วยความพ่ายแพ้**; ไม่มีฉากแก้มือในภาคนี้

## โครงตอนที่เสนอ (จำนวน 15 ตอนและผลย่อยปรับได้)

| ตอน | เนื้อเรื่องหลัก | จุดประสงค์ |
|---|---|---|
| 1 — ยินดีต้อนรับกลับ พี่ลูน่า | ชีวิตประจำวันสามคน มุกแหย่และแฟชั่น; เร็นกับมิโอะคุยตั้งทีม ลูน่าอาสา | ให้คนอ่านรักตัวละครก่อนเริ่มแข่งขัน |
| 2 — Operator ที่ดูไม่จริงจัง | ลูน่าสอบผ่านและตั้งทีมอย่างเป็นทางการ | พิสูจน์ว่าลูน่าทำงานเก่งจริง |
| 3 — ปืนสองกระบอก | ฝึกจำลองภายในทีม โชว์ Run & Gun ของเร็นและการยิงสนับสนุนของมิโอะ | แนะนำความสามารถทุกคน |
| 4 — ทีมที่ยังไม่เข้าขา | ฝึกจำลองแบบเปลี่ยนตำแหน่งและสื่อสารภายใต้ความกดดัน | เผยว่าเร็นเก็บปัญหาและมัวสนใจเป้าหมายตรงหน้า |
| 5 — Rank Wars #1 | แข่ง B กลุ่มล่างครั้งแรก ชัยชนะที่โชว์ฝีมือ | สร้างความมั่นใจ |
| 6 — ดูรีเพลย์ | พัก วิเคราะห์ข้อเสียและความสัมพันธ์สามคน | ฝังข้อบกพร่องทีมที่ยังไม่แก้ |
| 7 — Rank Wars #2 | เจอทีมเน้น Attacker; เร็นต้องรักษาระยะ | ขยายบทมิโอะและลูน่า |
| 8 — Rank Wars #3 | พบทีมระดับกลางที่รูปแบบเข้าทาง; ทดลองกติกาแมตช์ 4 ทีม | ชนะหรือทำอันดับสูงได้ แม้ไม่เหนือกว่าทุกด้าน |
| 9 — Hound ที่ยังไม่ถนัด | ซ้อมเรียน Hound/Grasshopper; เริ่มตั้งคำถามเรื่องการมองวิถีกระสุน **หลังใช้ Hound** | วางทางสู่การค้นพบ Bullet Line โดยไม่ให้ใครรู้ล่วงหน้า |
| 10 — Rank Wars #4 | ทีมเน้นป้องกัน; ต้องหามุมเจาะและช่วยกันยิง | แสดงพัฒนาการการประสานงาน |
| 11 — Rank Wars #5 | คู่แข่ง Sniper เก่ง; มิโอะเด่นและเร็นถูกทดสอบจุดอ่อน | ชัยชนะที่มีน้ำหนักก่อนพบกำแพง |
| 12 — ชื่อบนตาราง | จับคู่พบโอซามุ ฮิวส์ จิกะ; ศึกษาข้อมูลและเตรียมแผน | สร้างความคาดหวังและความกังวล |
| 13 — ฮิวส์และจิกะ | Rank Wars #6 เริ่ม; ฮิวส์กดประชิด จิกาคุม/ทำลายที่กำบัง | บดข้อได้เปรียบด้านระยะของเร็น–มิโอะ |
| 14 — Shooter ผู้ควบคุมสนาม | โอซามุใช้กระสุนน้อยแต่ปิดทางหนีและประสานกับฮิวส์–จิกา | ชี้ให้เห็นความต่างของประสบการณ์และการใช้ทรัพยากร |
| 15 — กำแพงของผู้มีพรสวรรค์ | ทีมเร็นพยายามเต็มที่แต่แพ้ขาด; สามคนเผชิญความจริงหลังจบแมตช์ | **ปิดภาคแรกด้วยความพ่ายแพ้** |

## ตัวอย่างการเลื่อนสายในการแข่ง (ยังไม่ล็อกผลย่อย)
- #1 อันดับ 1 จาก 3 ทีม → สายบน
- #2 อันดับ 1 จาก 3 ทีม → สายบน
- #3 อันดับ 2 จาก 4 ทีม → สายบน
- #4 อันดับ 1 จาก 3 ทีม → สายบน
- #5 อันดับ 1 จาก 4 ทีม → สายบน
- #6 พบทีมโอซามุท้ายภาค → **แพ้ขาด**
- กฎจริงในนิยาย: 3 ทีม อันดับ 1 ไปสายบน อันดับ 2–3 ไปล่าง; 4 ทีม อันดับ 1–2 ไปบน อันดับ 3–4 ไปล่าง. ดู [[Future_B_Rank_Wars_Two_Lanes]].
- **ผลย่อยห้าเกมเป็นเพียงคำแนะนำ** อย่าถือเป็นผลการแข่งขันล็อก

- Bullet Line มีอยู่ก่อนแล้วแต่ทั้งตัวเร็นและเพื่อนร่วมทีม **ไม่รู้** จนหลังเร็นใช้ Hound; อย่าทำให้รู้แผนของโอซามุอัตโนมัติ
- ลูน่าทำหน้าที่ Operator ได้ยอดเยี่ยม ความพ่ายแพ้ไม่ใช่ผลจากการทำให้ลูน่าด้อยความสามารถ
